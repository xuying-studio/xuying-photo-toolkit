## لماذا تحتاج إليه؟

بعد جلسة التصوير، توجد مهام متكررة يسهل أن تسبب أخطاء عند تنفيذها يدوياً:

- 📁 تنتشر ملفات RAW وJPG وملفات XMP الجانبية داخل مجلدات فرعية، وتحتاج إلى نظام تسمية يعتمد على تاريخ الالتقاط.
- 🧹 تترك عمليات التصدير أو النسخ ملفات JPG أو RAW بلا ملف مطابق، بينما يبدو حذفها بالجملة محفوفاً بالمخاطر.
- ⭐ تحتاج العلامات التي وضعتها في Adobe Bridge إلى المزامنة بين ملفات JPG وRAW.
- 🛡️ تريد معالجة كمية كبيرة من الملفات مع تجنب الكتابة فوق الملفات والحذف الخاطئ والتغييرات التي لا يمكن التراجع عنها.

تحوّل مجموعة أدوات التصوير شيوينغ العملية إلى: **فحص ومعاينة → مراجعة الأعداد → تأكيد وتنفيذ → تراجع عند الحاجة**.

| 🕒 إعادة التسمية حسب وقت الالتقاط | لتوحيد أسماء RAW وJPG وملفات XMP الجانبية | معاينة أولاً، منع التعارض، إعادة تسمية على مرحلتين، وإمكانية التراجع |

<a id="quick-start"></a>

## 🚀 البدء السريع

### استخدام تطبيق macOS

1. نزّل ملف `.dmg` من صفحة [Releases](https://github.com/xuying-studio/xuying-photo-toolkit/releases).
2. افتح الملف واسحب `旭影的摄影工具集.app` إلى مجلد التطبيقات.
3. افتح التطبيق، وحدد مجلد الصور، ثم اضغط أولاً على **الفحص والمعاينة**.

> يستخدم الإصدار الحالي توقيعاً محلياً من نوع ad-hoc ولم يحصل على توثيق Apple Developer ID. عند تشغيله لأول مرة على جهاز Mac آخر، قد تحتاج إلى النقر بزر الماوس الأيمن على التطبيق واختيار **فتح**.

### التشغيل من المصدر

المتطلبات: macOS 11 أو أحدث، Python 3.10 أو أحدث، وTkinter المتوفر مع macOS/Python.

```bash
git clone https://github.com/xuying-studio/xuying-photo-toolkit.git
cd xuying-photo-toolkit
python3 -m pip install -r requirements.txt
python3 main.py
```

### تشغيل أول آمن

1. انسخ مجموعة صغيرة من RAW/JPG إلى مجلد اختبار.
2. اختر صفحة إحدى الميزات واضغط **الفحص والمعاينة**.
3. راجع الإحصاءات وقائمة الملفات المنتظرة.
4. نفّذ العملية وتحقق من النتيجة.
5. عالج المشروع الكامل بعد التأكد من أن العينة تعمل كما هو متوقع.

للاطلاع على الصيغ المدعومة وقواعد التسمية وسلوك الاسترداد وحل المشكلات، اقرأ [الدليل الكامل](docs/使用说明.md).

<a id="workflows"></a>

## 🧭 كيفية عمل الوظائف الثلاث

### 🕒 إعادة التسمية حسب وقت الالتقاط

يفضّل التطبيق وقت الالتقاط في EXIF، ويستخدم وقت تعديل الملف كخيار احتياطي:

```text
DSC26-07-25-00001.arw
DSC26-07-25-00001.jpg
DSC26-07-25-00001.xmp
```

تتم إعادة تسمية الملفات الجانبية لملف RAW المطابق معه. وتبقى الملفات التي تستخدم هذه الصيغة دون تغيير، بينما يستمر الترقيم بعد أعلى رقم موجود في ذلك اليوم.

### 🧹 تنظيف أزواج RAW / JPG

تتم المطابقة داخل **المجلد نفسه** باستخدام الجزء الأساسي من الاسم مع تجاهل حالة الأحرف:

```text
A001.JPG  ↔  a001.ARW
```

يمكنك اختيار **JPG بلا RAW** أو **RAW بلا JPG**. تُنقل الملفات إلى سلة مهملات macOS بدلاً من حذفها نهائياً. يستخدم الاسترداد أولاً النسخة الآمنة المخفية، ثم يلجأ إلى Finder عند الحاجة.

### ⭐ مزامنة نجوم ووسوم ألوان Adobe Bridge

يدعم التطبيق الاتجاهين `JPG → RAW` و`RAW → JPG`، ويمكنك مزامنة النجوم أو وسوم الألوان أو كليهما.

- عند الكتابة إلى RAW، يتم إنشاء أو تحديث ملفه الجانبي `.xmp` فقط.
- عند الكتابة إلى JPG، تُنشأ نسخة احتياطية كاملة قبل تحديث XMP المضمّن.
- إذا فشل عنصر واحد في الدفعة، تتم استعادة الأهداف التي عولجت بالفعل تلقائياً.

## 🎨 المظهر والبيانات المحلية

يتبع التطبيق مظهر macOS الفاتح أو الداكن. يتيح خيار **المظهر…** ضبط الشفافية لحظياً بين 70% و100%، والقيمة الافتراضية هي 92%.

ملف الإعدادات:

```text
~/Library/Application Support/旭影的摄影工具集/ui_config.json
```

للتوافق مع سجلات التراجع القديمة، تحتفظ مجلدات النسخ الاحتياطية التشغيلية باسمها التاريخي. راجع [قسم البيانات المحلية في الدليل الكامل](docs/使用说明.md#8-本地数据与隐私).

<a id="build"></a>

## 🧰 البناء من المصدر

```bash
chmod +x build_app.sh
./build_app.sh
```

ينفذ البرنامج النصي مجموعة الاختبارات كاملة ثم ينشئ تطبيقاً وملفي ZIP وDMG يدعمان Apple Silicon وIntel.

يستخدم البناء الافتراضي توقيع ad-hoc. للتوزيع دون تحذير التشغيل الأول، جهّز شهادة Apple Developer ID Application وملف تعريف `notarytool`.

---

## 📦 البرامج النصية المستقلة القديمة

يحتفظ المستودع بالبرامج النصية الثلاثة الأصلية للرجوع إليها:

- `根据时间重命名文件排序.py`
- `根据RAW:JPG双向同步.py`
- `同步颜色与星号标记.py`

للاستخدام اليومي، يُفضّل تشغيل `main.py` أو تطبيق macOS؛ فالتطبيق الموحد يضيف إحصاءات الفحص التكراري وحماية التعارض واسترداداً أكثر اكتمالاً.
