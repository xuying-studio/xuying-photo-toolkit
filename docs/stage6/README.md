# 阶段 6 · Mac 平台视觉增强验收

日期：2026-09-06

## 状态

**阶段 6 的 Mac 部分已完成：原生磨砂、页面与控件动效、队列重排动画和系统“减少动态效果”联动均已接入，并通过源码版与打包版实机检查。**

Windows 的 Reduced Motion 默认值、高 DPI、窗口缩放、实体背景、回收站与中文路径专项测试仍延期，因此阶段 6 还不能标记为双平台整体完成。

## 已交付

### macOS 原生材质

- 新增独立 Swift 动态库，将 `NSVisualEffectView` 安装在 Qt 内容视图的同级下方。
- 原生材质层永远不接收鼠标事件，页面、按钮、画布和列表继续由 QML 处理交互。
- 窗口使用透明背景，七套主题中的玻璃类皮肤可显示系统原生材质；实体皮肤仍由主题色完整覆盖。
- 组件保留单一句柄并在应用退出时清理，不会因主题切换反复叠加视图。

### 动效与交互

- 四个页面常驻 ViewModel 状态，切换时使用淡入与轻微位移动画。
- 主按钮与导航按钮增加完整动效下的悬停、按压和弹簧回弹反馈。
- 关键词快切队列使用模型级 `rowsMoved` 与 QML `move/displaced` 动画，不再为一次排序重建整个列表。
- 侧栏共享核心状态面板支持展开、折叠和透明度过渡。
- 系统“减少动态效果”开启时自动切到无位移动画策略；关闭时恢复完整动效。用户仍可在界面中手动选择完整、减少或关闭。
