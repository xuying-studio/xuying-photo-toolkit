## 阶段 0 关闭条件

以下四项全部满足后才能关闭阶段 0：

1. Windows OCR 两后端同夹具结果与真实 21 图结果已记录。
2. macOS `pyside6-deploy` 与 Windows 至少一种正式候选打包路径产物已实际启动。
3. 用户确认 OCR 与打包主路径，并接受安装包体积/发布形态取舍。
4. 所有未关闭高风险项已有进入后续阶段前的明确测试门禁。
