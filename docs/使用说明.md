# 使用说明

## 1. 使用前请先了解这些原则

- 应用只处理你选定的当前文件夹；不会进入任何子文件夹。
- 扫描阶段只读取文件与元数据，不会改名、写入标记或移动文件。
- 只有点击执行并在确认框中确认后，才会开始修改文件。
- 每次重要操作完成后，请先检查结果，再进行下一次批量操作。
- 任何批量处理前都建议准备独立备份；本应用提供撤回机制，但不能替代完整备份策略。

## 2. 支持的文件格式

支持 JPG/JPEG 与以下 RAW 格式：

`ARW`、`CR2`、`CR3`、`CRW`、`NEF`、`NRW`、`RAF`、`RW2`、`ORF`、`PEF`、`DNG`、`X3F`、`3FR`、`FFF`、`SRW`、`MRW`、`MOS`、`ERF`、`IIQ`、`KDC`、`MEF`、`RAW`、`GPR`。

扩展名不区分大小写。隐藏文件夹及其内容不会被扫描。

## 3. 根据拍摄时间重命名

### 处理规则

1. 选择包含照片的文件夹，应用只扫描该文件夹当前层级，备份子文件夹不会参与处理。
2. 点击“扫描并预览”，程序优先读取 EXIF 拍摄时间；读不到时使用文件修改时间。
3. 同一拍摄日期按时间排序，生成格式为 `DSCYY-MM-DD-00001.ext`，例如 `DSC26-07-25-00001.ARW`；扩展名会保留原来的大小写。
4. 同名 RAW 的 `照片名.xmp` 和 `照片名.RAW.xmp` 侧车都会保留各自命名方式同步改名。
5. 已符合该格式的照片保持不变；同一天已有编号会从最大编号继续。
6. 文件名中无法提取原始数字的照片会跳过，并在扫描提示中列出。

### 安全与撤回

- 若目标名称已存在、多个文件会产生相同目标路径，程序会提示冲突并禁止执行。
- 实际改名使用两阶段临时文件名，避免互换名称时覆盖文件；发生错误会尽力回滚。
- 每次执行都会保存完整清单。点击“撤回最近一次”可恢复 RAW、JPG 和全部已记录侧车；重命名后新产生且无同名冲突的配套侧车也会一并恢复原名。

## 4. RAW / JPG 配对清理

### 配对规则

配对依据是**同一个文件夹内、文件名主干相同**的 RAW 与 JPG/JPEG；文件名不区分大小写。例如：

- `A001.JPG` 与 `a001.ARW` 视为一对。
- 子文件夹不会参与扫描，其中的同名文件不会被处理或配对。

### 操作步骤

1. 选择文件夹。
2. 选择要清理的格式：
   - `JPG（没有对应 RAW）`：找出孤立 JPG/JPEG。
   - `RAW（没有对应 JPG）`：找出孤立 RAW。
3. 点击“扫描并预览”，检查待清理列表和统计信息。
4. 点击“移入废纸篓”并确认。
5. 如需撤销，点击“恢复最近一次清理”。

### 恢复机制与权限

- 清理不会永久删除文件，而是移入照片所在磁盘对应的 macOS 废纸篓或 Windows 回收站。
- Windows 不会在原照片文件夹创建安全恢复副本；点击恢复时，程序会定位本次清理对应的回收站项目并直接还原到原位置。
- macOS 会在本次照片集合的共同目录下创建隐藏恢复副本；同一磁盘优先使用硬链接，不支持时才复制文件。恢复副本不可用时会再尝试废纸篓记录或 Finder。
- macOS 可能询问是否允许应用控制 Finder。该权限仅用于从废纸篓恢复文件。
- 若原位置已有同名文件，应用不会覆盖，并会在结果中报告该文件未恢复。

确认恢复成功后，废纸篓中的副本仍可能存在；请根据自己的备份策略决定是否清空废纸篓。

## 5. Adobe Bridge 星标与颜色标签同步

### 可选方向

- `JPG → RAW`：读取 JPG 中的 XMP 星标/颜色标签，写入同名 RAW 的 `.xmp` 侧车。
- `RAW → JPG`：读取 RAW 的 `.xmp` 侧车，写入同名 JPG 的内嵌 XMP。

可单独选择“同步星标”或“同步颜色标签”，但至少要选择一项。默认同步方向为 `JPG → RAW`。

### 处理边界

- 仅处理来源文件中存在有效星标（1–5）或非空颜色标签的项目。
- RAW 原始文件永远不会被直接写入；应用只创建或更新 `.xmp` 侧车。
- JPG 目标文件会在写入前完整备份；RAW 目标侧车如原本存在，也会备份。
- 本批次任一文件写入失败时，程序会自动恢复已经处理的目标，避免留下半完成状态。
- 点击“撤回最近一次同步”可恢复最近一批尚未撤回的同步。

## 6. 扫描统计信息

每个功能页都会在扫描后显示统计卡片：

| 页面 | 主要统计项 |
| --- | --- |
| 时间重命名 | 扫描照片、RAW、JPG、待改名照片、同步改名 XMP、冲突 |
| 配对清理 | 扫描照片、RAW、JPG、已有配对、待清理 |
| 星标与颜色同步 | 扫描照片、来源文件、成功匹配、带标记、待同步 |

列表最多显示 1,000 行预览；这不会改变实际扫描和处理范围。

三个功能页在扫描、执行和撤回过程中都会显示统一的总进度条，包括当前完成数量、总数量与实时百分比。涉及两个安全阶段的操作（例如重命名的临时改名与最终写入、XMP 同步的备份与写入）会把两个阶段合并计入同一条总进度。

## 7. 外观皮肤

点击侧栏底部“外观…”可以选择七套工作区皮肤：

- **专业深黑**：默认皮肤，强调克制、清晰和高密度操作。
- **星雾深蓝**：深海军蓝层级与柔和蓝紫环境光。
- **流光玻璃**：轻盈通透的蓝灰玻璃材质与高亮边缘。
- **模块拼盘**：暖橙强调色与清晰的模块化工作区。
- **编辑部极简**：纸张暖白、细线层级与摄影杂志气质。
- **极光空间**：深夜空间层级与紫绿极光状态光。
- **柔软三维**：浅灰蓝浮雕层级与柔和低饱和控件。

点击“应用皮肤”后会立即重建主界面，并保留当前页面、共享照片文件夹和窗口尺寸。后台任务运行时不能换肤；存在扫描预览时会先确认，继续后预览和临时列表会被清空。关键词快切会同步使用同名皮肤，照片画布区域始终保持中性，不受主题背景色影响。

新版不再提供透明度调节，主窗口和外观窗口始终保持完全不透明。旧配置中的透明度字段会被忽略，首次保存后配置文件只记录皮肤 ID：

- 配置位置：`~/Library/Application Support/旭影工具箱/ui_config.json`

首次启动会依次读取“旭影的摄影工具集-关键词内嵌版”和“旭影的摄影工具集”的旧皮肤配置；没有皮肤字段或皮肤已失效时自动使用“专业深黑”。迁移后只写入“旭影工具箱”目录，不删除旧配置。

## 8. 本地数据与隐私

应用不包含网络上传功能。以下本地记录用于撤回操作：

| 用途 | 默认位置 |
| --- | --- |
| 重命名撤回清单 | `~/Library/Application Support/摄影文件后期处理助手/rename_backups/` |
| XMP 同步完整备份 | `~/Library/Application Support/摄影文件后期处理助手/xmp_backups/` |
| 最近一次清理记录 | `~/Library/Application Support/摄影文件后期处理助手/cleanup_undo.json` |
| 清理安全恢复副本（仅 macOS） | 所选照片共同目录下的隐藏 `.摄影文件后期处理助手-恢复备份/` |
| 关键词快切设置（仅 macOS） | macOS `UserDefaults`；首次读取旧对齐器设置，之后保存到内嵌版应用域 |

Windows 会把前三项业务记录保存到 `%APPDATA%\摄影文件后期处理助手\` 下，目录结构和文件名保持一致；不会在照片目录生成清理备份文件夹。

为保证旧版本的撤回记录仍可使用，这些业务数据目录保留了历史名称。

## 9. 关键词快切

关键词快切是工具集内嵌的原生离线工作区。点击侧栏“关键词快切”后，完整界面会直接显示在当前窗口右侧，不会启动额外 App。

主要流程：

1. 导入 PNG、JPG、JPEG 或 HEIC 截图并输入关键词。
2. 使用 Apple Vision OCR 识别文字，逐张确认精确或模糊匹配候选。
3. 调整统一目标位置，导出处理后 PNG、逐帧 PNG 序列或无声 MP4。

关键词快切不会覆盖原始截图，也不需要网络。内嵌版工具集要求 macOS 13 或更高版本及 Apple Silicon Mac；旧版工具集和现有安装包保持不变。

## 10. 常见问题

### 扫描后没有待处理文件

请确认选择的是正确的根文件夹；程序会忽略隐藏目录、未支持的格式，以及已经符合目标状态的文件。

### 重命名时提示冲突

程序不会覆盖现有文件。请先移动、改名或移除冲突目标，再重新扫描。

### 恢复清理时提示 Finder 权限

在“系统设置 → 隐私与安全性 → 自动化”中允许“旭影工具箱”控制 Finder，然后再次执行恢复。若存在安全恢复副本，通常无需该权限。

### Windows 首次打开出现安全提醒

当前 Windows 测试版尚未进行代码签名，SmartScreen 可能提示“Windows 已保护你的电脑”。请先确认安装包来自本项目，再选择“更多信息 → 仍要运行”。这不会要求管理员权限。

### 其他 Mac 无法直接双击打开

使用 Apple Developer ID 签名并完成苹果公证后重新构建。未公证的自编译版本可能需要右键选择“打开”。

### 如何报告问题

请不要发送真实照片或完整私人路径。建议提供脱敏后的文件名示例、复现步骤、macOS 版本、应用版本和完整错误文本。
