# 阶段 5 · Mac 关键词快切验收

日期：2026-09-06

## 状态

**阶段 5 的 Mac 部分已完成：Apple Vision OCR、图片队列、候选选择、目标框编辑和三种导出均已接入。**

Windows 离线 OCR 与实机验收仍延期，因此阶段 5 还不能标记为双平台整体完成。

## 已交付

### Apple Vision OCR

- 新增无界面的 Swift 动态库，只负责调用 Apple Vision 和转换坐标，不再嵌入旧 SwiftUI 页面。
- 使用准确识别、简体中文与英文、语言校正，以及与 v1.4.0 相同的最小文字高度。
- 精确匹配优先；无精确结果时使用 0.70 相似度阈值、中心距离排序和候选去重。
- OCR 缓存使用图片内容 SHA-256 与关键词，同路径图片被替换后不会误用旧结果。

### 队列与编辑

- 支持 PNG、JPG、JPEG、HEIC；支持多文件、文件夹当前层和拖放导入。
- 过滤隐藏项、符号链接、非图片和嵌套目录；规范路径去重并自然排序。
- 使用 QML `ListView` 与 `QAbstractListModel` 虚拟化队列；提供缩略图、点击选择、删除、上下移动和拖动排序。
- 每张图片保留候选列表，可手动切换；未匹配图片仍按原图居中输出并显示提醒。
- 目标框可拖动、右下角缩放、复位，并始终限制在画布范围内。
- 页面切换后队列、选择、目标框和参数仍由 ViewModel 保留。

### 渲染与导出

- 处理后 PNG：按队列顺序输出，尺寸与对齐画布一致。
- 逐帧 PNG：连续六位编号，总数等于图片数乘每图帧数。
- MP4：H.264、无音轨，支持 23.976、29.97、59.94 等有理数时间基。
- 输出目录包含关键词和时间，不覆盖同秒旧结果；非法文件名字符会被清理。
- 识别与导出均在后台运行、显示进度并可取消；取消或失败时清理 `.partial` 半成品。

### 设置迁移

- 新设置写入 v2 独立目录。
- 首次没有 v2 设置时，只读导入旧 `com.xuying.keyword-aligner` 域中的 `KeywordAligner.ProjectSettings.v1`。
- 不修改、不删除旧版设置。
