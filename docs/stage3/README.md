# 阶段 3 · Mac 设计系统与主框架验收

日期：2026-09-06

## 状态

**阶段 3 的 Mac 设计系统与主框架已完成，Windows 实机验收仍延期。**

本阶段只建立 QML 视觉层、组件和占位页面，没有连接 ViewModel，也没有执行任何照片扫描、改名、清理、XMP 写入或 OCR。

## 视觉方向

界面采用“摄影暗房工作台”方向：高密度、克制、强调任务状态与执行前预览。主结构由标题栏、工具侧栏、页面工作区和状态栏组成。图片/视频画布固定为中性 `#15171B`，不跟随皮肤变色，避免影响色彩判断。

## 已交付

- 主窗口、顶栏、侧栏、状态栏、四页路由与 `Ctrl+1`–`Ctrl+4` 快捷键。
- 七套共用 Token 皮肤：专业深黑、星雾深蓝、流光玻璃、模块拼盘、编辑部极简、极光空间、柔软三维。
- `Full` / `Reduced` / `None` 三档动效策略；动效只改变视觉属性。
- Button、Field、Select、Table、Dialog、Toast、Progress、面板、页头、指标签和主题选择器。
- 统一的鼠标悬停、按下、选中、禁用、键盘焦点环和无障碍名称。
- 1300×760 最小布局、1×/2× DPI 启动、换肤后页面状态保留。
- 八张真实 QML 渲染截图：七套皮肤的重命名页，以及专业深黑的关键词快切页。
