## 已交付

### 时间重命名

- QML 页面、ViewModel 和虚拟化预览模型。
- 默认只扫描当前文件夹，可选包含子文件夹。
- 显示 RAW、JPG、XMP、跳过项、警告和命名冲突。
- 必须先预览再确认执行；冲突时禁止执行；支持最近一次撤回。

### RAW/JPG 配对清理

- 支持孤立 JPG 与孤立 RAW 两种扫描方向。
- 同目录、同主文件名、大小写不敏感配对。
- 只移入 macOS 系统废纸篓，触碰原文件前先保留恢复副本和记录。
- 恢复不覆盖原位置同名文件，部分失败时保留未完成记录。
- 新扫描失败时会在用例层立即废弃旧预览，不可误执行上一批文件。

### Adobe XMP 同步

- `JPG → RAW` 与 `RAW → JPG` 双向同步，星标与颜色标签可独立选择。
- RAW 只写侧车，不直接修改 RAW 原文件。
- 写入前整批备份，每个目标使用原子替换，批次失败自动回滚。
- 执行后保存 SHA-256 指纹；撤回前发现 Bridge/Lightroom 等后续修改时，整批停止并保留备份，不覆盖新内容。
- 分步撤回进度落盘，中途异常后可继续处理未完成项。

### 界面与并发

- 三页均使用 `QAbstractListModel` 虚拟化渲染，适用于大批量照片。
- 扫描任务在 `QThreadPool` 后台运行且可取消；原子提交、恢复和撤回阶段明确不可中断。
- 页面切换时 ViewModel 状态由应用生命周期保留。
- 三个页面均接入了预览、进度、取消、二次确认、反馈和错误状态。
